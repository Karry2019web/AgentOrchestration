## Artifact Provenance

Starting with version 2.5.0, all release artifacts include **SLSA Build L3 provenance attestations**
generated by the GitHub Actions release workflow.

### Verifying Release Artifacts

Each published artifact carries a cryptographically signed provenance statement.
You can verify it using the GitHub CLI:

```bash
# Verify an artifact's provenance
gh attestation verify <artifact-file> --repo orchestration-agent/AgentOrchestration

# Download the attestation for offline verification
gh attestation download <artifact-file> --repo orchestration-agent/AgentOrchestration
```

The attestation includes:
- Source repository and commit SHA
- Workflow run that produced the artifact
- Artifact digest (SHA-256)
- Build environment metadata

This ensures every release artifact can be traced back to the exact source code
and CI pipeline that built it.

## Reporting a Vulnerability

We take security seriously. We run a **Bug Bounty Program** to encourage responsible disclosure.

**To participate in the bug bounty:**

1. ⭐ **Star this repository** — All bounty participants must have starred the repo
2. Open a security issue using the Bug Bounty template
3. Provide a detailed description of the vulnerability
4. Include steps to reproduce
5. Submit a PoC if possible

**Bounty rewards:**

| Severity   | Reward        |
| ---------- | ------------- |
| Critical   | $5,000 - $10,000 |
| High       | $2,000 - $5,000  |
| Medium     | $500 - $2,000    |
| Low        | $100 - $500      |

We typically respond within 24 hours and resolve critical issues within 72 hours.
